# React Learning

This repository contains the things I worked on while learning React. I started with the basics and slowly moved towards more practical concepts and projects.

The main goal was to understand how React works by writing code and building small examples instead of just learning the theory.

## React Basics

I started by getting familiar with the basic structure of a React application and how different files and folders are organized.

I then moved on to components and props. I learned how to create reusable components and how to pass data from one component to another using props.

I also created a small cards project to practice these concepts and get more comfortable with breaking a UI into smaller reusable components.


## Styling and State

After getting comfortable with components and props, I started working on styling React applications.

I practiced using CSS with React and worked on a small UI project to understand how components can be combined to create an actual interface.

After that, I started learning about state using the `useState` hook. This helped me understand how React keeps track of changing data and updates the UI when the state changes.

I practiced state management with different examples and user interactions to get a better understanding of how `useState` works.

## Forms, Data and Storage

Next, I started working with forms and user input in React.

I learned how to handle form inputs, manage their values using state, and handle form submissions. I also worked with two-way binding to understand how the value of an input can stay connected with the state.

I then built a simple Notes App where I practiced adding, displaying, and removing data using React state.

After that, I learned how to use browser local storage. I used it to save data so that it would still be available even after refreshing the page.

I also started working with APIs and learned how to fetch data from external sources and display it inside a React application.
